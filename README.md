# 광주광역시 복지 지원사업 데이터 수집 및 웹 표시

## 프로젝트 개요
광주광역시 홈페이지에서 복지 관련 데이터를 수집하고, 웹 페이지에 테이블 형태로 표시하는 프로젝트입니다.

## 수집 정보
- **기관명**: 복지 지원사업을 담당하는 기관
- **지원사업명**: 복지 지원사업의 이름
- **지원내용**: 구체적인 지원 내용 및 조건

## 파일 구성
- `index.html`: 복지 데이터를 테이블 형태로 표시하는 웹 페이지
- `welfare_data.json`: 수집된 복지 지원사업 데이터 (JSON 형식)
- `scraper_simple.py`: 웹 스크래핑 스크립트 (기본 라이브러리 사용)
- `requirements.txt`: Python 패키지 의존성

## 실행 방법

### 1. 데이터 수집
```bash
python3 scraper_simple.py
```

### 2. 웹 서버 실행
```bash
python3 -m http.server 8000
```

### 3. 웹 페이지 접속
브라우저에서 `http://localhost:8000/index.html`에 접속하여 결과를 확인합니다.

## 수집된 데이터 현황
- **총 지원사업**: 20개
- **참여기관**: 6개 (보건소, 사회복지과, 아동복지과, 여성가족과, 노인복지과, 장애인복지과, 교육청)

## 주요 복지 지원사업
1. **난임부부 지원사업**: 체외수정, 인공수정 시술비 지원
2. **국민기초생활보장**: 생계급여, 주거급여, 의료급여, 교육급여
3. **아동수당**: 만 8세 미만 아동 월 10만원 지원
4. **기초연금**: 만 65세 이상 어르신 월 최대 334,810원 지원
5. **장애인연금**: 중증장애인 기초급여 및 부가급여 지원

## 기술 스택
- **Python 3**: 웹 스크래핑 및 데이터 처리
- **HTML/CSS/JavaScript**: 웹 페이지 구현
- **JSON**: 데이터 저장 형식

## 특징
- 반응형 웹 디자인 (모바일 친화적)
- 실시간 데이터 새로고침 기능
- 통계 정보 표시 (총 지원사업 수, 참여기관 수)
- 아름다운 그라데이션 UI 디자인
- 호버 효과 및 애니메이션
